## Integrations

### Blockchain Networks

T402 supports 47 networks across 13 blockchain families:

| Category | Networks |
|----------|----------|
| EVM Chains | Ethereum, Arbitrum, Base, Optimism, Ink, Berachain, Unichain |
| Non-EVM | TON, TRON, Solana, NEAR, Aptos, Tezos, Polkadot, Stacks, Cosmos |

## Building on T402

### Extension Points

T402 is designed for extensibility:

1. **Custom Payment Schemes** - Implement new payment logic
2. **Chain Mechanisms** - Add support for new blockchains
3. **Transport Adapters** - Beyond HTTP (MCP, A2A, WebSocket)
4. **Middleware Plugins** - Custom validation and logging
