\chapter{Error Code Reference}
\label{app:errors}

This appendix provides a complete reference of \tprotocol{} error codes, organized by category. Each error includes a machine-readable code, human-readable description, and recommended resolution.

Payment errors occur during the payment authorization phase, typically due to insufficient funds, invalid signatures, or parameter mismatches.

\section{Error Response Format}

All \tprotocol{} errors are returned in a consistent JSON format:

\begin{lstlisting}[language=json, caption={Error Response Structure}]
{
  "error": {
    "code": "insufficient_funds",
    "message": "Payer balance (1.50 USDT) is less than required (5.00 USDT)",
    "details": {
      "required": "5000000",
      "available": "1500000",
      "asset": "0x6C96dE32CEa08842dcc4058c14d3aaAD7Fa41dee",
      "network": "eip155:1"
    }
  }
}
\end{lstlisting}

\begin{itemize}
\item \textbf{code}: Machine-readable error code from tables above
\item \textbf{message}: Human-readable description
\item \textbf{details}: Optional object with error-specific context
\end{itemize}
