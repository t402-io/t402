## Why T402?

<Cards>
  <Cards.Card title="HTTP Native" href="/getting-started/concepts">
    Pay for any HTTP resource with a single header. No payment forms, no redirects, no SDKs required.
  </Cards.Card>
  <Cards.Card title="Multi-Chain" href="/chains">

import { t402Client } from '@t402/fetch'

## How It Works

<Steps>
### Client makes request

```
GET /api/premium HTTP/1.1
Host: api.example.com
```

### Server returns 402 Payment Required

```
HTTP/1.1 402 Payment Required
Payment-Required: scheme="exact";network="eip155:8453";amount="10000";...
```

### Client signs and retries

```
GET /api/premium HTTP/1.1
Payment-Signature: signature="0x...";payload="..."
```

### Server verifies and responds

```
HTTP/1.1 200 OK
Content-Type: application/json
{"data": "Premium content!"}
```

</Steps>

- Ethereum, Arbitrum, Base, Optimism, Polygon, Ink, Berachain, Unichain

**Non-EVM Chains**
- **Solana** - SPL Token USDC (mainnet, devnet)
- **TON** - USDT Jetton (mainnet, testnet)
- **TRON** - TRC-20 USDT (mainnet, nile, shasta)
- **NEAR** - NEP-141 USDT (mainnet, testnet)
- **Aptos** - Fungible Asset USDT (mainnet, testnet)
- **Tezos** - FA2 USDt (mainnet, ghostnet)
- **Polkadot** - Asset Hub USDT (polkadot, westend)
- **Stacks** - SIP-010 USDT (mainnet, testnet)
