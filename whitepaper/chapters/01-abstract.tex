\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

\begin{quote}
\textit{T402 is an open payment protocol that enables HTTP-native stablecoin payments. By leveraging the HTTP 402 ``Payment Required'' status code, T402 provides a standardized mechanism for web services to require and process cryptocurrency payments without intermediaries.}
\end{quote}

\vspace{1em}

The proliferation of web services, APIs, and AI agents has created an unprecedented demand for seamless, programmable payments. Traditional payment systems, with their high fees (\$0.30+ per transaction), settlement delays (2-5 business days), and geographic restrictions, are fundamentally incompatible with the pay-per-use economics of the digital age. Micropayments below \$0.50 are economically unviable with credit card processing, leaving a vast design space unexplored.

\tprotocol{} addresses these challenges through a novel payment protocol that bridges web standards with blockchain settlement:

\begin{itemize}
    \item \textbf{Utilizes HTTP 402}: First practical implementation of the long-dormant HTTP 402 ``Payment Required'' status code, originally reserved in HTTP/1.1 (1997) for future digital payment systems

    \item \textbf{Supports 10 Blockchain Families}: Unified interface across EVM networks (19+ chains including Ethereum, Base, Arbitrum), Solana, TON, TRON, NEAR, Aptos, Tezos, Polkadot Asset Hub, Stacks, and Cosmos

    \item \textbf{Enables Gasless Transactions}: Leverages EIP-3009 (Transfer with Authorization) and similar mechanisms on non-EVM chains, allowing users to pay without holding native tokens for gas fees

    \item \textbf{Integrates with AI}: Native support for MCP (Model Context Protocol) and A2A (Agent-to-Agent) communication, enabling autonomous AI agents to discover, evaluate, and pay for resources programmatically

    \item \textbf{Minimizes Trust}: Cryptographic binding ensures facilitators cannot redirect funds---recipients are specified in signed authorizations, and facilitators can only submit transactions that honor these specifications

    \item \textbf{Sub-Cent Micropayments}: Transaction costs under 1\% enable previously impossible business models---API calls at \$0.001, sensor data at \$0.0001, per-article content access
\end{itemize}

The protocol separates concerns into three layers: \emph{Types} (transport-agnostic data structures using CAIP-2 network identifiers), \emph{Logic} (chain-specific payment schemes like ``exact'' and ``up-to''), and \emph{Representation} (transport-layer encoding for HTTP headers, MCP tools, and A2A messages). This architecture enables extensibility across new blockchains and transport protocols while maintaining backward compatibility.

\vspace{0.5em}

\noindent\textbf{Ecosystem:}
\begin{itemize}
    \item \textbf{SDKs}: TypeScript (29 packages), Go, Python, Java
    \item \textbf{HTTP Integrations}: Express, Hono, Fastify, Next.js, Fetch, Axios
    \item \textbf{UI Components}: React, Vue, Universal Paywall
    \item \textbf{Infrastructure}: Public Facilitator API, Grafana monitoring
\end{itemize}

Production deployments demonstrate sub-cent transaction costs on Layer 2 networks, settlement finality in seconds (vs. days for traditional payments), and seamless integration with existing HTTP infrastructure requiring only 5-10 lines of middleware code.

The protocol is fully open-source under the Apache 2.0 license, with specifications, reference implementations, and this whitepaper available at \url{https://github.com/t402-io/t402}.
