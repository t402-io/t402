# MCP Integration

Enable AI agents like Claude to make stablecoin payments using the Model Context Protocol (MCP).

## Overview

The `@t402/mcp` package provides an MCP server that exposes T402 payment capabilities to AI agents. This enables use cases like:

- AI agents paying for API calls
- Automated payment workflows
- AI-powered financial assistants

## Architecture

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  Claude Desktop │────▶│   @t402/mcp     │────▶│   Blockchain    │
│  (MCP Client)   │     │   (MCP Server)  │     │   (EVM/TON/etc) │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

## Setup

### 1. Install the Package

```bash
npm install -g @t402/mcp
```

### 2. Configure Claude Desktop

Edit `claude_desktop_config.json`:

**macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
**Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "t402": {
      "command": "npx",
      "args": ["@t402/mcp"],
      "env": {
        "T402_PRIVATE_KEY": "0x...",
        "T402_DEMO_MODE": "true",
        "T402_WDK_SEED_PHRASE": "your twelve word seed phrase here"
      }
    }
  }
}
```

<Callout type="info">
  Setting `T402_WDK_SEED_PHRASE` enables 5 additional WDK tools (11 total). Without it, only the 6 base tools are available.
</Callout>

### 3. Restart Claude Desktop

The T402 tools will now be available to Claude.

## Available Tools

The MCP server provides 6 base tools, plus 5 additional WDK tools when a seed phrase is configured (11 total).

### Base Tools (6)

#### t402/verify
Verify a payment authorization against the facilitator.

#### t402/settle
Settle a verified payment on-chain via the facilitator.

#### t402/supported
List all supported networks, schemes, and signers.

#### t402/getRequirements
Get payment requirements for a 402-protected resource.

#### t402/getAllBalances
Check balances across all supported networks.

```
"What are all my stablecoin balances?"
```

#### t402/pay
Execute a stablecoin payment.

```
"Send 5 USDT0 to 0x1234... on Arbitrum"
```

### WDK Tools (5, requires `T402_WDK_SEED_PHRASE`)

#### wdk/getWallet
Get WDK wallet address and chain info.

#### wdk/getBalances
Check balances across all configured WDK chains.

#### wdk/transfer
Transfer tokens from the WDK wallet.

#### wdk/swap
Swap tokens via WDK on a given chain.

#### t402/autoPay
Autonomously fetch a 402-protected resource, sign the payment, and return the content.

## Demo Mode

For testing without real transactions:

```json
{
  "mcpServers": {
    "t402": {
      "command": "npx",
      "args": ["@t402/mcp"],
      "env": {
        "T402_DEMO_MODE": "true"
      }
    }
  }
}
```

In demo mode:
- No private key required
- Returns simulated balances and transactions
- Safe for development and testing

## Custom RPC Endpoints

Configure custom RPC URLs for better reliability:

```json
{
  "env": {
    "T402_PRIVATE_KEY": "0x...",
    "T402_RPC_ETHEREUM": "https://eth.llamarpc.com",
    "T402_RPC_BASE": "https://base.llamarpc.com",
    "T402_RPC_ARBITRUM": "https://arb1.arbitrum.io/rpc"
  }
}
```

## Security Best Practices

1. **Use environment variables** for private keys
2. **Enable demo mode** during development
3. **Set spending limits** in your workflows
4. **Monitor transactions** via block explorers
5. **Use separate wallets** for AI agents

## Troubleshooting

### MCP Server Not Found

Ensure `@t402/mcp` is installed globally:

```bash
npm install -g @t402/mcp
```

### Connection Errors

Check that Claude Desktop is properly configured and restarted.

### Transaction Failures

- Verify sufficient balance for amount + gas
- Check network status
- Ensure private key has correct permissions

## Integration with Policy Engine

Use `@t402/policy` to set spending guardrails for MCP agents:

```typescript
import { PaymentPolicyEngine } from "@t402/policy";

const policy = new PaymentPolicyEngine({
  maxAmountPerPayment: "1000000",    // 1 USDC max per payment
  maxAmountPerSession: "10000000",   // 10 USDC session budget
  maxPaymentsPerHour: 100,
  allowedNetworks: ["eip155:8453", "eip155:42161"],
});
```

## Integration with Observability

Track all MCP payment activity with `@t402/observability`:

```typescript
import { PaymentEventCollector, toPrometheusMetrics } from "@t402/observability";

const collector = new PaymentEventCollector();
// Expose metrics at /metrics
app.get("/metrics", (req, res) => {
  res.type("text/plain").send(toPrometheusMetrics(collector.getMetrics()));
});
```
