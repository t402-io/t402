# Services

This directory contains web services for the t402 ecosystem.

| Service | Description | URL | Status |
|---------|-------------|-----|--------|
| `site/` | Marketing website | [t402.io](https://t402.io) | ✅ Production |
| `docs/` | Documentation site (Nextra) | [docs.t402.io](https://docs.t402.io) | ✅ Production |
| `demo/` | Interactive demo (9 scenarios) | [demo.t402.io](https://demo.t402.io) | ✅ Production |
| `facilitator/` | Payment facilitator (Go, private) | [facilitator.t402.io](https://facilitator.t402.io) | ✅ Production |
| `scan2pay/` | Merchant payment gateway (Java+Next.js, private) | [scan2pay.t402.io](https://scan2pay.t402.io) | ✅ Production |
| `bazaar/` | Service marketplace for AI agent discovery | — | 🆕 New |

The `facilitator` and `scan2pay` services are private submodules.
