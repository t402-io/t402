🎯 Getting Started Guide

▼
1
Check Supported Networks

Click to see available testnet networks and their upstream status.

2
Verify a Payment (Magic Address)

Select a network, switch to the /verify tab, and click "Try It". The example uses magic address 0x...CAFE01 which always returns isValid: true.

3
Settle the Payment

Switch to /settle and send. You'll get a mock transaction hash back.

4
Test Error Handling

Change the payer address to 0x...CAFE02 (signature failure) or 0x...CAFE12 (insufficient funds) and re-send to test error paths.

5
Test Webhooks

Switch to /webhook/test to send a test callback to your server. Use httpbin.org for testing.

✓
Ready for Integration

Copy SDK code from any request using the buttons below. Point your SDK at https://sandbox.t402.io and you're ready to build!
