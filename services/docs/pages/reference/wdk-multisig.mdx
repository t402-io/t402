# @t402/wdk-multisig

Safe multi-signature wallet integration for enterprise treasury management.

```bash
npm install @t402/wdk-multisig
```

## Overview

Integrate Safe (formerly Gnosis Safe) multi-sig wallets with t402 payments. Enables M-of-N signing for payment approval, transaction queuing, and module-based extensions.

## Features

- Safe protocol integration (multi-sig)
- M-of-N signing threshold for payment approval
- Transaction queue management
- Module support for automated payments
- Compatible with Safe Core SDK
