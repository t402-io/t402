# @t402/wdk-gasless

Gasless USDT0 payments via EIP-3009 and ERC-4337 account abstraction.

```bash
npm install @t402/wdk-gasless
```

## Overview

Users pay zero gas fees. The facilitator sponsors gas via:
- **EIP-3009** `transferWithAuthorization` — token moved directly without approve step
- **ERC-4337** UserOperations — bundler handles gas, paymaster sponsors fees

## Supported Networks

All 25 EVM networks with USDT0 (EIP-3009 support).

## How It Works

1. Client signs EIP-3009 `transferWithAuthorization` (off-chain, no gas)
2. Facilitator submits the signed authorization on-chain (pays gas)
3. Token transfers directly from payer to merchant
4. Payer never needs native token (ETH/MATIC/etc.)
